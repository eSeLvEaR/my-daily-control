# My Daily Control – PWA (Android)

Αυτή η έκδοση είναι έτοιμη για δωρεάν φιλοξενία σε GitHub Pages και εγκατάσταση ως εφαρμογή PWA.

## Περιλαμβάνει
- Τρέχουσα λειτουργικότητα V3: εργασίες, focus timer 15/20/25/30 λεπτών, εβδομαδιαίο ημερολόγιο, ιστορικό 30 ημερών.
- Ελεύθερος χρόνος 60΄ ή 90΄ με κλείδωμα μετά την επιλογή για την ημέρα.
- Σταθερή συμφωνία χωρίς οθόνες στις 21:30.
- Χωρίς περιοχή γονέα.
- Offline app shell μέσω service worker.
- Εικονίδια 192×192 και 512×512.
- Διόρθωση καταγραφής χρόνου του focus timer.

## Δωρεάν δημοσίευση με GitHub Pages
1. Συνδέσου ή δημιούργησε λογαριασμό στο https://github.com/
2. Δημιούργησε νέο repository, π.χ. `my-daily-control`. Μπορεί να είναι Public.
3. Αποσυμπίεσε το ZIP και ανέβασε **τα περιεχόμενα** του φακέλου στο βασικό επίπεδο (root) του repository. Το `index.html` πρέπει να βρίσκεται απευθείας στο root.
4. Στο repository άνοιξε **Settings → Pages**.
5. Στο **Build and deployment**, διάλεξε **Deploy from a branch**.
6. Επίλεξε branch `main` και folder `/ (root)` και πάτησε **Save**.
7. Περίμενε να ολοκληρωθεί το deployment. Η διεύθυνση θα είναι περίπου:
   `https://ΤΟ-USERNAME.github.io/my-daily-control/`

## Εγκατάσταση στο Android tablet
1. Άνοιξε την παραπάνω HTTPS διεύθυνση με **Google Chrome**.
2. Περίμενε να φορτώσει πλήρως μία φορά ενώ υπάρχει Internet.
3. Πάτησε το μενού ⋮ του Chrome.
4. Επίλεξε **Install app / Εγκατάσταση εφαρμογής** ή **Add to Home screen / Προσθήκη στην αρχική οθόνη**.
5. Άνοιξε το εικονίδιο από την αρχική οθόνη. Θα εμφανίζεται σαν αυτόνομη εφαρμογή.

## Σημαντικό για τα δεδομένα
- Τα δεδομένα αποθηκεύονται τοπικά στο συγκεκριμένο browser και στη συγκεκριμένη συσκευή.
- Η PWA δεν συγχρονίζει αυτόματα δεδομένα ανάμεσα σε διαφορετικές συσκευές.
- Μην καθαρίζεις τα δεδομένα του Chrome ή της εφαρμογής, γιατί μπορεί να διαγραφεί το ιστορικό.
- Χρησιμοποίησε τακτικά **Εξαγωγή δεδομένων (JSON)** και φύλαξε το αρχείο backup.
- Το offline άνοιγμα λειτουργεί αφού γίνει η πρώτη επιτυχής φόρτωση online.
- Για να παραμείνει σταθερή η εγκατάσταση, μην αλλάξεις το GitHub repository name ή τη διεύθυνση δημοσίευσης μετά την εγκατάσταση.

## Ενημέρωση εφαρμογής
Αν ανεβάσεις νεότερα αρχεία, αύξησε το `CACHE_NAME` στο `sw.js` (π.χ. `my-daily-control-pwa-v2`). Έτσι θα κατέβει νέο cache στην επόμενη σύνδεση.
